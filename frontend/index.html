Project Overview:

This project demonstrates a containerized web application. It includes a frontend that fetches an image from the backend service and displays status information. The goal is to showcase DevOps practices including containerization, service proxying, and Kubernetes-based orchestration.

Technology Stack:

  • Frontend: HTML5, CSS3, JavaScript served via nginx (or static server)
  • Backend: Flask (Python) RESTful API
  • Containerization: Docker
  • Orchestration: Kubernetes (Minikube / cluster)

Key Features:

  • Microservices architecture with separate frontend and backend
  • Backend-proxied image served below all text
  • Simple REST endpoint for status and health checks
  • Dockerized deployment for consistent environments

✨ Image served from Backend Service via Kubernetes internal DNS (http://backend:5000/image)
